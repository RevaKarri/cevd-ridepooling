This is the code for the paper "Conditional Expectation based Value Decomposition for Efficient and Sustainable On-Demand Ride Pooling".

To run the code, you need to install CPLEX 20.1, tensorflow, keras, scikit-learn.

main_vanilla.py runs NeurADP over which our work is an improvement.

main_plus.py followed by main_scoring.py runs CEVD, our proposed approach.
